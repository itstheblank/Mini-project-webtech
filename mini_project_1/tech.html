Frontend Technologies

Các công nghệ phổ biến để xây dựng giao diện người dùng bao gồm React, Vue.js, Angular, hoặc sử dụng thuần HTML/CSS/JS với các thư viện hỗ trợ như W3.CSS, Tailwind CSS. Giúp tạo ra các giao diện SPA (Single Page Application) mượt mà.

Backend Frameworks

Ở phía server, các công nghệ như Node.js (Express/NestJS), Python (Django/Flask), Java (Spring Boot) hoặc PHP (Laravel) đóng vai trò xử lý logic nghiệp vụ, quản lý phiên người dùng và trả về dữ liệu qua API.

Database Systems

Lưu trữ dữ liệu có thể sử dụng cơ sở dữ liệu quan hệ (SQL) như MySQL, PostgreSQL đảm bảo tính toàn vẹn dữ liệu (ACID). Hoặc NoSQL như MongoDB cho các dự án cần sự linh hoạt và khả năng mở rộng nhanh (Scalability).

IT4409 - Công nghệ Web

Dự án thực hành xây dựng trang web tĩnh sử dụng HTML, CSS và W3.CSS framework.
