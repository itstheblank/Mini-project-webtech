Giới thiệu chung

Mã môn học: IT4409

Tên môn học: Công nghệ Web và Dịch vụ trực tuyến

Số tín chỉ: 3 (2 lý thuyết - 1 thực hành)

Môn học này là một phần quan trọng trong chương trình đào tạo kỹ sư CNTT, giúp sinh viên nắm bắt và áp dụng công nghệ mới nhất vào xây dựng hệ thống phần mềm nền web.

Mục tiêu môn học

Trang bị kiến thức và kỹ năng lập trình web toàn diện (Full-stack):

  • Hiểu rõ kiến trúc Client-Server, HTTP Protocol.
  • Thành thạo HTML5, CSS3, JavaScript.
  • Biết cách sử dụng các framework phổ biến hiện nay.
  • Hiểu về bảo mật web cơ bản và thiết kế dịch vụ RESTful API.

Nội dung cốt lõi

Nội dung bao gồm lập trình frontend, backend, quản trị cơ sở dữ liệu và triển khai (deploy) ứng dụng web lên server thực tế (Cloud).

IT4409 - Công nghệ Web

Dự án thực hành xây dựng trang web tĩnh sử dụng HTML, CSS và W3.CSS framework.
